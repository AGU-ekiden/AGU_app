# 会員ラベル作成 (label_create)

スプレッドシートにまとめた会員データから、印刷用のラベルシートをブラウザ上で作成するアプリです。
有料会員向けを想定した、黒×ゴールドの高級感あるラベルテンプレートを同梱しています。
バックエンドは持たない静的Webアプリで、データは一切サーバーに送信されず、すべてブラウザ内で処理されます。

## できること

- CSV/Excelファイルから会員データを読み込み、または差出人ラベルを手入力+枚数指定で作成
- 見出し名から氏名・住所・会員番号などの列を自動マッピング(手動修正も可能)
- 黒×ゴールドの高級感あるラベルテンプレート(ロゴ画像アップロード対応)
- 市販のラベル用紙規格プリセット(10面/12面/24面/44面)+ 完全カスタムmm指定
- 印刷位置のオフセット微調整(プリンター・用紙の個体差を吸収)
- ブラウザの印刷機能で直接印刷、または「PDFに保存」

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で `dist/` に静的ファイルを出力します。Vercelにそのままデプロイ可能です
(`vercel.json` 同梱、Vite Frameworkとして自動認識されます)。

1行目は見出し(列名)にしてください(例: 氏名, フリガナ, 会員番号, プラン, 郵便番号, 住所)。

## 印刷のコツ

- 用紙プリセットの実寸はメーカーによって微妙に異なります。まず1枚だけテスト印刷し、
  実際のラベル用紙と重ねて確認してください
- ズレる場合は「印刷位置の微調整」の横/縦オフセットで補正してください
- 用紙プリセットに無いサイズは「カスタム(自由入力)」で正確な寸法を入力してください

## 拡張性

### テンプレートを追加する

`src/templates/` に新しいフォルダを作り、以下を用意します。

1. `LabelTemplateProps`(`src/types/index.ts`)を実装するReactコンポーネント。
   `widthMm` / `heightMm` を受け取り、CSS側もmm単位でサイズを決めることで
   どのラベルサイズでも正しく表示されます(`src/templates/elegantGold/` を参照)。
2. コンポーネントを説明する `TemplateDefinition` を返す `meta.ts`
3. `src/templates/registry.ts` の `TEMPLATES`配列に追加

これだけでテンプレート選択画面に自動的に表示されます。

### 用紙プリセットを追加する

`src/data/paperPresets.ts` の `PAPER_PRESETS` 配列に、寸法・列数・行数・余白を
指定したオブジェクトを追加するだけです。

### 項目(列)を追加する

`src/data/fieldDictionary.ts` の `FIELD_DEFINITIONS` に、キーとエイリアス
(自動マッピング用の見出し候補)を追加し、`src/types/index.ts` の
`CanonicalFieldKey` にキーを追加してください。

## 技術構成

- Vite + React + TypeScript(静的SPA、バックエンドなし)
- CSVパース: papaparse / Excelパース: exceljs(動的import、初期バンドルには含まれません)
- 印刷: CSS `@page` によるmm単位の正確なページサイズ指定 + ブラウザ標準の印刷/PDF保存
